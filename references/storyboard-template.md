# 分镜表模板

开工时先填这张表，再动 `film.js`。一句一行，`a`/`b` 是这句字幕出现/消失的时刻（秒），对着 BGM 的击点取。

- 观众看完应该记住的那一句：____
- 全片唯一的"尺"（贯穿的形象）：____

## 4. 字幕表（14 句左右）

| # | a | b | 中文 | English |
|---|---|---|---|---|
| 1 | 0.7 | 3.7 | | |
| 2 | 4.1 | 6.7 | | |
| 3 | 7.1 | 9.7 | | |
| … | | | | |

写法要求：

- 一句一个动作；句子里出现动词，屏上就要真的做那个动作。
- 提问句、命名句、结论句不硬配图。
- 关键词用 `{词}` 标金色、`{!词}` 标红，交给 `K.subs` 处理。
- 中文量一遍宽度，≤1400px；英文一行放得下。

| 鼓点回归 | | 转折章 |
